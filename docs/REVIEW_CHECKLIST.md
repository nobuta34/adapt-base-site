# 初版確認事項

本番mainは維持し、feature/business-site-v1を同じCloudflare Pagesのプレビューで確認する。

- contact/privacyの新規作成と送受信
- プロフィール・対応時間・所在地の掲載可否
- サービスの受注可能範囲
- 価格、税区分、契約・支払条件
- 個人情報の運用・保持期間

これらを確認後に初版の準備中表記を修正し、PRをmainへ反映する。本番反映は別途指示後。CF_PAGES_BRANCHがmain以外の環境はnoindex・確認版バナー。本番mainではバナーとnoindexは除去される。準備中の窓口は確認完了まで送信リンクを置かない。
