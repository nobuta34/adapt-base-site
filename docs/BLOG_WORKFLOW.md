# 「考えと実践」の執筆・公開

掲載先: https://adapt-base.com/insights/blog/

## 執筆から公開まで

1. チャットでGPTと壁打ちするか、本人の原案を渡す。
2. GPTが論点・構成・文章を整理する。補った解釈や推測は本人へ示し、本人の意見として確定しない。
3. 本人が内容、顧客情報等の公開可否、著者名の公開表記を確認する。
4. リポジトリ外の非公開作業場所に保存し、ローカル画面で確認する。
5. 本人が対象の記事の公開を指示する。
6. 承認された原稿だけを `content/insights/blog/<slug>/index.md` へ登録し、`draft: false` とする。画像を使う場合は同じ記事フォルダーへ、公開を確認したものだけ置く。
7. ビルドとリンクを検査し、mainへ反映する。Cloudflare Pagesの公開後、記事一覧と本文を確認する。

記事は公開日の新しい順に表示する。著者名は記事ごとに本人が確認した表記を指定する。氏名の未確認時は推測で埋めない。

## 原稿の形式

空のひな型は `archetypes/blog.md`。タイトル、概要、公開日時、確認済みの著者名を記入する。更新した場合は `lastmod` を明示指定し、公開日時より後の場合だけ更新日を表示する。日時は `2026-11-01T16:00:00+08:00` のように時差付きで指定する。

`draft: true` は通常ビルドから除外される。未来の公開日時も通常ビルドでは除外されるが、自動予約配信は提供しない。未来日時を過ぎても、再ビルドするまでは公開されない。

## 未公開原稿の保護

このGitHubリポジトリは公開されている。下書きフラグやnoindexを付けても、登録した原稿自体は公開される。未公開原稿はブランチ・PR・コミット・添付を含めて登録しない。

ローカル確認では、公開リポジトリ外の一時フォルダーにサイトのコピーを作り、そこへ原稿を入れる。元のチェックアウトでは作業しない。そのコピーでのみ以下を実行する（PowerShell）。

```powershell
hugo server --buildDrafts --bind 127.0.0.1 --port 1313
```

ブラウザーで `http://127.0.0.1:1313/insights/blog/` を開く。公開プレビューへ転送せず、原稿と添付を非公開のまま確認する。終わったらサーバーを止める。

## 確認コマンド

Hugo 0.154.5をPATHに入れた環境で実行する。別の場所の実行ファイルを使う場合は、`HUGO_BIN` に絶対パスを指定する。

```powershell
$env:PYTHONUTF8 = '1'
python scripts/test_blog.py
$env:CF_PAGES_BRANCH = 'main'
hugo --gc --minify
python scripts/check_site.py public
```

試験用原稿は一時フォルダー内に生成し、サイトの原稿として登録しない。記事0件の状態は正常であり、機能確認のために本人名義の架空記事は作らない。
